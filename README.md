🧠 Core mental models
HTML pages are no longer separate files — the UI is now component-driven
The UI is built from reusable pieces
Frontend applications have architecture, not just pages
Routing controls views without reloading the browser
Components receive data and render predictable UI
Large applications are composed of smaller isolated systems
This is the foundation of modern frontend engineering.
